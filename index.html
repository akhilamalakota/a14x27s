FAQ

Good to know
Is a14x27s free?

Yes. It is an open-source, non-commercial project built for research and educational purposes.

Why can't I install the APK?

Android blocks apps from outside the Play Store by default. Enable Install unknown apps for your browser or file manager, then open the file again. If Play Protect warns you, tap Install anyway.

Which devices are supported?

Any Android 7.0+ phone. This APK ships the arm64-v8a native library, which covers virtually every phone made since ~2016.

Do I need a Last.fm account?

No — the app works without one. Signing in unlocks scrobbling, algorithmic taste mixes and the personalized discovery radar.

Is it affiliated with YouTube or Last.fm?

No. a14x27s is an independent project and is not affiliated with or endorsed by Google, YouTube, Spotify, Apple or Last.fm. All trademarks belong to their respective owners.
